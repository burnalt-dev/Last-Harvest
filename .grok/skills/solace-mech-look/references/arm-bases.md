# Arm bases

Every arm part picks **A / B / C**. Spec card must say `BASE: ape | crane | stork`.

Split stays: **shoulder + upper** on `armL`/`armR` (open wrist). **Grip + tool** on `handL`/`handR` / `hands`.

| Base | Grey? | Anim (`solace-mech-anim`) |
|------|-------|---------------------------|
| A ape | later | hang, extra elbow, teeter idle, windmill charge |
| B crane | **grey / slice 1** | hinge fold, slower unfurl |
| C stork | later / weird-stat | telescope, sway, tip-warning pose |

Do not add a D wrap-around-chest base. That fuses to body.
